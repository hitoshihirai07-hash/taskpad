使い方

TaskPad（ブラウザ内で完結するタスクメモ）

できること

  • タスク追加（スマホは「＋」からクイック追加：期日プリセット＋カテゴリプリセット）
  • タブ：今日 / 今週 / あとで（今週より先） / 期限なし / 設定
  • カテゴリ：プリセットを自由に追加・削除（ローカル保存）＋カテゴリで絞り込み
  • 並び替え：期日 / 優先度 / 作成日（全タブ共通）
  • 検索：タイトル/メモを横断検索（/ または Ctrl+K で検索へ、Esc でクリア）
  • ゴミ箱：削除はまずゴミ箱へ移動（復元OK / 「完全削除」「空にする」は戻せません）
  • TSVコピー・JSONバックアップ（必要なときだけ外部に貼り付け）

データの保存場所

  • タスクデータは ブラウザのローカル保存（localStorage） に保存されます。
  • ログイン機能はありません。別端末・別ブラウザには同期されません。
  • ブラウザのデータ削除や初期化で消える可能性があります。

ざっくり操作

  • 追加：PCは右上「＋追加」/ スマホは下の「＋」
  • 編集：タスク行をタップ → 期日 / 優先度 / 状態（未着手/進行中/完了）/ カテゴリ / メモ
  • 削除：まずゴミ箱へ（画面下のトーストで Undo / Ctrl+Z でも復元）
  • カテゴリ：設定でプリセットを作る → 編集画面とクイック追加で使えます
  • 今週/あとで：日付見出しをタップすると折りたたみできます

バックアップ（おすすめ）

  • 設定の TSVコピー：スプレッドシート等に貼り付け
  • 設定の JSONバックアップをコピー：テキストに保存（自分用メモでもOK）
