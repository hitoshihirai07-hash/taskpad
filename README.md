# TaskPad (MVP)

自分用タスク管理の最小構成（静的HTML/JS + localStorage）。

## 仕様（ざっくり）
- 予定日 = 期日（締切）
- スマホ下タブ：今日 / 今週 / ＋ / 期限なし / 設定（＋で期日プリセット：今日/明日/なし）
- 追加はタイトルだけでOK（後から編集）
- 今日：期限切れ / 今日が期日 を最上段で強調
- 設定：TSVコピー、JSONバックアップ、Inbox（カテゴリ未設定）、完了、全削除

## Cloudflare Pages 推奨設定（静的）
- Build command: `exit 0`
- Build output directory: `public`
- Root directory: `.`

`public/` の中がそのまま配信されます。


## 追加（v2）
- ＋追加に期日プリセット（今日/明日/なし）
- 設定で「今週の範囲」（日曜まで / 7日先まで）を切替


## 方針
- TaskPad内で完結（状態/期日/カテゴリ/メモで管理）
- 必要なときだけTSVやJSONをコピーして、外部に貼り付け可能


## 追加（v4）
- 設定でカテゴリプリセットを追加/削除（ローカル保存）
- カテゴリで絞り込み（上部フィルタ＆設定内セレクト）
- 今週タブの日付見出しを折りたたみ


## 追加（v6）
- ＋クイック追加にカテゴリプリセット（ボタン方式）
- 状態表示を日本語（未着手/進行中/完了）


## 追加（v7）
- 「あとで」タブ追加（今週より先の期日）
- 並び替え（期日/優先度/作成日）を追加（上部＆設定）
